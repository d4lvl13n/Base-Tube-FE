# Agent skills

`basetube-upload/` teaches an AI coding agent to upload and manage Base.tube videos with the `basetube` CLI.

- **Claude Code:** copy the folder to `~/.claude/skills/` (all projects) or to `.claude/skills/` in one project: `cp -r basetube-upload ~/.claude/skills/`.
- **Codex:** copy the folder into your project, then reference it from your `AGENTS.md`, for example: "To upload videos to Base.tube, follow `skills/basetube-upload/SKILL.md`."
